# Guild-Wars2-ArcDPS-Korean-translation

길드워2 ArcDPS 한글 번역.<br>
AI로 번역하여 오역 및 틀린 번역이 많을 수 있습니다.<br>
잘못 된 부분은 알려주시면 수정하도록 하겠습니다.<br>

## 사용법

- (길드워2 경로)\addons\arcdps 경로에 아래 3개의 파일을 넣으면 됩니다.<br>
  - arcdps_lang.ini<br>
  - arcdps_table_lang.ini<br>
  - arcdps_font.ttf<br>
- 처음 한번만 작업하면 그 뒤로는 자동 업데이트 됩니다.

## 번역 참고

- 분 -> 이로운 효과<br>
- 컨디션 -> 상태 이상 (분과 컨디션은 일관성을 위해 길드워2 한글 패치와 동일하게 번역)<br>
- Dodge -> 닷지<br>
- Defiance bar -> 브레이크바<br>
- CC -> 군중 제어<br>
- Crowd Control -> 군중 제어<br>
- cleanse, strip -> 원문에 Condition에는 cleanse, Boon에는 strip을 사용하는 것 같으며, cleanse는 '제거', strip은 '해제'로 할까 하다가 '제거'로 통일함<br>
